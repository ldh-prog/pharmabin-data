폐의약품 수거함 찾기(kr.ulsan.ldh.pharmabin) 개인정보처리방침

시행일: 2026년 10월 13일(앱 1.0.0부터)

1. 목적

본 앱은 공공데이터포털 「전국폐의약품수거함표준데이터」로 폐의약품 수거함의 위치·세부 위치·관리기관 연락처와 약 종류별 배출 방법을 보여 줍니다. 회원 가입, 로그인, 결제, 광고를 쓰지 않으며 이름·전화번호·이메일 등 개인정보를 수집하지 않습니다. 위치 권한은 이용자가 「현재 위치로 가까운 수거함 찾기」를 누를 때만 요청하고, 위치는 기기 안에서 거리 계산에만 씁니다.

2. 처리하는 정보

  • 선택한 시·도 코드: 그 지역 수거함 데이터 파일을 받기 위해 파일 주소에 넣어 GitHub Pages(ldh-prog.github.io)로 요청합니다.
  • 현재 위치(「현재 위치로 찾기」를 누른 경우에만): 전국 수거함 좌표 파일(points.json)을 받아 기기 안에서 가까운 시·도를 고르고, 그 시·도의 데이터 파일을 요청합니다. 위치 자체는 서버·제3자에게 보내지 않고 기기 저장소에도 남기지 않습니다. 백그라운드 위치는 쓰지 않습니다.
  • 검색어와 시·군·구 선택: 기기 안에서만 걸러 쓰며 외부로 보내지 않습니다.
  • 기기 저장소: 받아 둔 수거함 목록 사본(인터넷이 끊겼을 때 보여 주기 위해 최대 60일), 마지막으로 고른 찾기 방법·시·도·시·군·구와 배출 요령 펼침 여부, 「여기 없었어요」 표시(최대 180일). 모두 이 기기에만 있고 외부로 보내지 않습니다.
  • 통신 시 IP 등 네트워크 정보: HTTPS 통신 과정에서 GitHub 서버에 전달될 수 있습니다. 개발자는 접속 기록을 받지 않고 저장하지 않습니다.
  • 안드로이드 권한: 인터넷, 네트워크 상태(위치 기능 라이브러리가 인터넷 연결 여부를 확인하는 데 씁니다. 설치할 때 자동으로 허용되며 개인정보를 읽지 않습니다), 위치(대략적·정확한 위치, 「현재 위치로 찾기」를 누를 때만 요청). 저장소·주소록·카메라 권한은 없습니다.

3. 보유와 파기

기기 저장소의 사본과 표시는 위 기간이 지나면 지워지고, 앱 삭제 또는 앱 데이터 삭제로 바로 지울 수 있습니다. Android 자동 백업은 꺼 두었습니다. 개발자는 공개 데이터 파일만 올리며 이용자 정보를 받는 서버가 없습니다.

4. 제3자·외부 서비스

개인정보를 판매하거나 광고에 쓰지 않습니다.

  • GitHub Pages(GitHub, Inc., ldh-prog.github.io/pharmabin-data): 수거함 데이터 파일 제공. 공공데이터포털 「전국폐의약품수거함표준데이터」를 개발자가 받아 올린 사본이며 앱은 공공데이터포털에 직접 연결하지 않습니다. GitHub 서버는 국외(미국 등)에 있을 수 있습니다.
  • 카카오맵·네이버지도·스마트서울맵·공공데이터포털: 이용자가 버튼을 누른 경우에만 앱 밖에서 열립니다. 수거함 이름·주소·좌표(공공정보)가 주소에 포함될 수 있습니다.
  • 전화: 이용자가 관리기관 전화번호를 누른 경우에만 휴대폰 전화 앱으로 그 번호가 전달됩니다.

처리 위탁, 광고·분석·로그인 SDK는 없습니다.

5. 안전성

외부 통신은 HTTPS만 사용합니다.

6. 이용자 권리

수집한 개인정보 파일이 없습니다. 기기에 남은 사본과 표시는 앱 삭제 또는 저장공간 삭제로 지울 수 있습니다.
